# Generated demo pictures

The five `generated-*.webp` assets were created on 2026-10-31 with the built-in
Imagegen tool, one generation per object, and encoded as WebP without changing
the composition. They depict fictional inventory, not real products or stock.
The seed uses only these generated images. Checksums and dimensions are in
`scripts/demo-seed-manifest.mjs`. No image generation occurs in the running demo.

All prompts use `product-mockup`, an inventory demo item photograph, landscape
3:2 framing, natural detailed materials and soft daylight. Full prompts:

## generated-drill.webp

Use case: product-mockup
Asset type: inventory demo item photograph
Primary request: photorealistic catalog photo of a cordless 18V drill with two batteries in an open fitted black tool case on a tidy wooden workshop bench.
Composition/framing: landscape 3:2, complete tool case visible, three-quarter view, natural detailed materials, soft daylight.
Constraints: fictional unbranded tool, no people, no text, no logos, no watermark. This image illustrates a fictional inventory demo.

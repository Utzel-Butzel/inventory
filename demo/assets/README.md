# Demo context photography

These photographs are bundled for the read-only workshop demo. They are real
contextual photographs from Pexels, not photographs of the seeded inventory
records, users, or an Open Inventory deployment. The app alt text explicitly
describes them as context rather than evidence of the pictured item.

The files were downloaded under the
[Pexels licence](https://www.pexels.com/license/). Keep this attribution with
the files and review the current licence before redistributing an original
outside this project.

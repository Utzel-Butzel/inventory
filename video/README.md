# Open Inventory intro video

A 15-second, 1920×1080 Remotion introduction for Open Inventory. The animation
follows the project story from camera capture to an AI-assisted record, then
shows desktop and native iOS product proof before the branded end card.

## Commands

Install dependencies:

```console
npm i
```

Open Remotion Studio:

```console
npm run dev
```

Render the final H.264 video:

```console
npm run render
```

Render the end-card preview still:

```console
npm run still
```

Rendered files are written to `out/`. Source artwork is copied into
`public/marketing/` so the video is reproducible as a self-contained project.

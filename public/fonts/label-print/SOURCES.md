# Additional label fonts

These original variable TTF files are self-hosted and used by both the label preview and print image embedding. Each family includes upright and italic faces and its unmodified SIL Open Font License. No request to Google Fonts is made at runtime.

Source: [google/fonts](https://github.com/google/fonts/tree/6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec/ofl), revision `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`.

# Environment lighting assets

`studio_small_08_1k.hdr` is the **Studio Small 08** HDRI by Sergej
Majboroda, downloaded from [Poly Haven](https://polyhaven.com/a/studio_small_08).
It is provided under the [CC0 license](https://polyhaven.com/license).

The 1K Radiance HDR version is intentionally used here: it retains the full
dynamic range needed for lighting and reflections while keeping the initial
room-view download small.
